# 언어의 최소 골격 — 1차 검증 자료 v0.1

## 검증 입력

기존 일상 한국어 100문장의 원문과 번호를 유지했다. 10개 생활 영역별 10문장이다. 아래 맥락은 평가자가 입력으로 제공하는 정보다. 장면을 새로 설정한 예에서는 해당 맥락을 함께 읽는다. ‘—’는 별도의 서사를 지정하지 않았다는 뜻이며 화자와 청자, 발화 시점은 공통으로 주어진다. 99번처럼 맥락을 줘도 결정되지 않는 참조는 모호성 자체가 채점 대상이다.

## WRRA 변환과 채점

입력에서 발화 목적, 술어, 참여자 역할, 지시 대상과 부정·양태·시간·조건의 범위를 복원한다. 정정에서는 참조한 사건 및 변경·보존 필드를 함께 채점한다. 표현이 달라도 같은 역할과 범위를 보존하면 정답이다. 예를 들어 ‘민수가 지영이에게 우산을 빌려줬다’와 ‘지영이가 민수에게 우산을 빌렸다’는 같은 전달 관계로 채점한다. 여러 해석이 동등한 과제는 가능한 해석을 모두 유지하거나 구체적으로 확인 질문을 해야 완전 정답이다. 정답 형태를 읽어 주는 채점 보조 입력과 시스템에 제공하는 발화를 분리한다.

수준은 주된 시험 기능을 지정한다. 1은 즉시 요청·지시, 2는 사건·관계 표현과 조건 등, 3은 앞 대화 인출·정정, 4는 전언·앎·생각을 통한 관계 재결합이다. 의미 주석의 괄호 깊이와 별개다. 기능이 겹치는 사례는 가장 두드러진 기능을 한 개만 표기했다. 100문장 점수와 새로운 상황 변형 점수는 따로 기록한다.

## 산출값과 반증조건

이 버전에서 확정한 산출물은 원문 100개에 대응하는 채점 초안과 공개 상황 변형 16개다. 공개 변형은 개발용으로 쓴다. 실제 비교 전에는 이름·대상·표현이 겹치지 않는 별도 평가 세트를 고정하고, 구성요소 제거와 대화 상태 초기화를 대조한다. 평가 시 원문·변형 정확도, 상황별 통과 범위, 분석기·생성기·어휘·규칙의 설치 바이트, 최대 상태 메모리와 응답 시간을 기록한다. 모델 훈련이나 휴대폰 실측은 이 자료의 수치에 포함하지 않는다.

역할 반전 입력에도 역할이 그대로 나오면 역할 구분에 실패한 것이다. 정정에서 다른 필드까지 바뀌면 상태 갱신에 실패한 것이다. 대화 상태를 지웠는데도 대상을 고르면 문장 안의 단서나 기준선의 누출을 조사한다. 두 가지 해석이 가능한 99번을 단일 정답으로 강제하면 채점 설계 자체가 실패한다.
