# 일상 한국어 100문장과 WRRA 최소 구조 모델

## 검증 입력

집과 일과, 주문, 결제, 교통, 약속, 일과 학교, 몸 상태, 대화 복구, 계획, 관계 전달의 10개 상황에서 10문장씩 직접 작성했다. 실제 회화의 빈도 표본이나 별도 검증을 거친 주석은 아니다. 문장마다 상황을 하나 가정해 의미 구조를 부여했다. 화자·청자·우리·이것·앞발화 같은 항목은 장면이나 대화에서 해결해야 할 참조다. 물음표가 붙은 인수는 질문이 채우려는 값이다.

## WRRA 고유 변환 가설

1. **묶기** — 술어와 참여자의 역할을 하나의 관계로 저장한다. `빌려주다(민수,지영,우산)`에서 앞의 두 자리는 빌려주는 사람과 받는 사람이다.
2. **꺼내기** — 질문이 가리키는 관계와 역할을 찾아 읽는다. ‘아까’, ‘그 사람’, ‘방금’의 해석에는 이전 대화 상태가 필요하다.
3. **결합·갱신** — 저장한 관계를 전언·믿음·조건 등의 입력에 다시 쓴다. 정정 발화는 앞서 가리킨 대상을 새 대상으로 갱신한다. 94번과 95번은 생각하는 사람과 찾는 사람의 자리를 교환하는 대조쌍이다.
4. **표현하기** — 갱신 결과를 알림, 질문, 요청, 제안 등으로 실현한다. 표는 문장별 목표 의미를 적었으며, 원문을 자동 분석하는 모델의 성적표는 아니다.

## 산출값

문장 맨 바깥 발화 유형을 제외한 괄호 깊이는 1층 44문장, 2층 41문장, 3층 14문장, 4층 1문장이다. 이 수는 수작업 표기의 중첩 깊이다. 시간순서, 대상 수식, 부정도 포함하며, 인간의 작업기억 슬롯이나 신경회로의 깊이와 직접 대응시키지 않는다.

### 유한 상태 계산

| 과제 | 상태 수 | 최소 저장량 |
|---|---:|---:|
| 인물 4명과 사건 4개 중 한 쌍을 지정하고 두 역할을 나중에 질문 | 16 | 4비트 |
| 독립적으로 고른 두 쌍을 순서대로 저장하고 어느 쌍의 역할이든 질문 | 256 | 8비트 |
| 그 두 쌍에 ‘두 관계를 안다’의 인물 4명 중 하나를 묶고, 안쪽 역할과 바깥 인물 모두 질문 | 1024 | 10비트 |

세 과제는 내부 상태 하나에 입력을 보존하고, 원문이나 출력 기록을 다시 읽지 않으며, 가능한 어느 질문에도 정확히 답한다는 조건을 둔다. 바깥 인물은 안쪽 관계와 독립적으로 고른다. 정보가 다른 두 입력을 같은 상태에 넣으면, 차이가 있는 역할을 물었을 때 둘 모두 정답일 수 없다. 따라서 표의 비트 수는 정보 보존의 하한이다. 고정 폭으로 인물과 사건을 2비트씩 부호화하면 그 하한을 달성할 수 있다. 연산 회로, 주소 선택, 어휘 사전, 입력·출력의 비용은 별도다.

**실행 검산.** 인물과 사건을 각각 0~3으로 부호화했다. 관계 ID는 `4 × 인물 + 사건`, 두 관계 ID를 A·B라고 할 때 상태는 `16 × A + B`, 바깥 인물을 C라고 할 때 결합 상태는 `256 × C + 16 × A + B`다. 1,024개 조합 전체를 생성해 역변환으로 A·B의 역할과 C가 복원되는지 확인했다. 10비트는 1,024개 모두를 구별했다. 상위 1비트를 잘라낸 대조는 512개 상태, 상위 2비트를 잘라낸 대조는 256개 상태만 남아 바깥 인물에 대한 충돌이 발생했다. 이 검산은 명시적 부호화 모델에 대한 것이다.

## 반증조건과 AI 스케일링 실험

- **빈도·어순 대조** — 인물과 사건 어휘 수를 맞추고 역할만 교환한다. 기존 문장을 맞혀도 새 인물 조합이나 바뀐 역할에서 답을 똑같이 내면 관계 보존의 증거가 약하다.
- **잔여 제거 대조** — 앞선 문장을 재입력하지 못하게 하고 저장 상태를 초기화한다. 그래도 정확도가 유지된다면 질문 안의 단서나 다른 경로를 조사한다.
- **스케일링 비교** — 일반 모델과 동일한 기반 모델에 관계 저장·인출을 붙인 경우를 비교한다. 학습 토큰·연산 예산을 맞추고 파라미터 수, 추론 때 쓰는 상태 공간과 연산을 함께 기록한다. 새 인물·사건 조합과 학습보다 한 단계 깊은 관계를 따로 평가한다. 같은 일반화 성적에 필요한 모델 크기와 상태 공간이 달라지는지 측정한다.
- **발달과 유전** — 관계 유지·선택·재결합을 분리해 측정한 뒤, 각 기능이 발달하는 데 필요한 회로와 그 발달 조건을 살핀다. 이 표본으로 인간의 최소 뉴런 수와 최소 유전자 수를 추정하지 않는다.
