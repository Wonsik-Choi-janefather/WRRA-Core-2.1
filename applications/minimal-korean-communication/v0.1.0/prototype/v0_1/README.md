# 언어의 최소 골격 1차 실행 시제품

## 재현

압축을 푼 디렉터리에서 Python 3.9 이상으로 다음 명령을 실행한다. 외부 패키지는 필요 없다.

    python3 evaluate.py

`engine.py`가 어휘 분리형 실행기, `lexicon.json`이 어휘 데이터다. `baseline.py`와 `lookup.json`은 기준선이다. `results.json`은 저장한 1회 결과이며 실행 시간과 추적 메모리는 환경에 따라 달라질 수 있다.

## 검증 입력과 WRRA 변환

원문 100개의 입력은 목표 문장 하나다. 추가 장면 정보가 필요한 일부 문장도 전체 분모에 포함되므로 이 점수는 실생활 능력보다 구현 범위를 보는 보수적인 지표다. 기준선의 원문 점수는 사전에 넣은 동일 문장·정답을 조회한 값이다. 개발용 변형 16개 중 여러 턴 과제는 앞선 발화를 순서대로 입력한다. V07의 장면 정보는 실행기에 전달할 입력 통로가 아직 없다.

입력의 조사와 동사를 보고 주는 쪽·받는 쪽·물건을 결합한다. 약속 정정에서는 앞선 약속을 가져와 지정한 날짜나 장소만 바꾼다. ‘그 사실’을 묻는 경우에는 앞선 잠금 사건을 가져와 앎의 입력으로 쓴다. 직전 사실이 없으면 무엇을 가리키는지 확인한다. 결과는 의미 구조 문자열로 출력하고 동일한 포맷의 기대값과 비교한다.

## 산출값

| 시험 | 문장 조회 | 어휘 분리형 |
|---|---:|---:|
| 원문 100개 | 100/100 | 13/100 |
| 공개 개발 변형 16개 | 0/16 | 13/16 |
| 대여 관계의 생성 조합 432개 | 0/432 | 432/432 |
| 코드와 필수 데이터의 UTF-8 파일 크기 | 11,906바이트 | 7,369바이트 |

432개는 서로 다른 두 인물의 순서 있는 배정 12가지, 물건 3가지, 빌려주기·빌리기 표현 2가지, 어구 순서 6가지를 전수 조합했다. 일부 어순은 일상적 자연스러움보다 역할 구별을 시험하기 위한 것이다. 규칙과 같은 문형에서 만든 구조 검산이며 독립 수집 자료에서의 일반화 성적은 아직 없다. 어휘표에 ‘별컵’만 추가하면 코드 수정 없이 새 대여 관계를 읽는 것도 확인했다. 파일 크기는 서로 다른 범위의 시제품 규모이며 동일 정확도에서의 최소 크기 판정은 아직 남아 있다. Python 런타임은 제외했다. 시간과 메모리는 개발 환경의 참고값이며 휴대폰 실측과 전체 프로세스 메모리는 별도다.

## 반증 대조와 남은 범위

- 역할 결합을 끄면 V10~V12가 실패한다.
- 앞선 상태 보존을 끄면 V08·V09·V14가 실패한다.
- 정정에서 상태 갱신을 끄면 V08·V09가, 관계 재결합을 끄면 V06·V14·V16이 실패한다.
- 개발 변형에서 남은 실패는 V07(장면을 이용한 지시어 및 대체), V13(초점 구문이 포함된 믿음), V15(자기의 지시 대상 모호성)이다.
- 의미 구조에서 자유 문장을 만드는 생성기와 외부 검토자가 만든 평가 세트는 후속 범위다.
